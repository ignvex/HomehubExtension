# v1.0.0-alpha

首个对外版本。HomehubExtension 是 Homehub 宿主的自托管扩展服务：单 Go 二进制，
前端构建产物内嵌，提供 Pastebin、RSS 阅读器（媒体全量本地化）与 15 个纯浏览器
开发工具，并为宿主开一条签名认证的机器通道。

这是一个 **alpha** 版本：功能面完整，但尚未经过长期运行验证，API 契约仍可能
在 1.0.0 正式版前微调。适合自用与联调，不建议承载不可恢复的关键数据。

## 亮点

- **宿主持久凭证**：宿主通过 Ed25519 签名通道推送订阅、对账状态、签发用户
  访问密钥；Extension 不保存宿主账号，只存一把公钥。
- **零第三方请求的阅读器**：文章引用的图片、音视频、字体全部下载到内容寻址
  存储并重写为 `/media/<sha256>`，无法本地化的元素直接抹除。
- **匿名也能用的 Pastebin**：创建不需要登录，服务端返回一枚 owner token；
  分享页服务端渲染，`curl` 与爬虫可读。
- **单二进制交付**：`go build` 产物包含前端；systemd `Type=notify`，
  支持 watchdog 心跳与启动前迁移。

## 部署

```bash
# 1. 构建（会先构建前端），产物在 dist/，不压缩
make build

# 2. 安装
sudo install -m 0755 dist/homehub-extension /usr/bin/
sudo install -m 0644 deploy/hhe.service /etc/systemd/system/
sudo install -d -o root -g homehub -m 0750 /etc/hhe
sudo install -m 0640 -o root -g homehub config.example.json /etc/hhe/config.json
# 数据目录由 unit 里的 StateDirectory=hhe 创建为 /var/lib/hhe，不需要手工 mkdir
sudo systemctl daemon-reload
sudo systemctl enable --now hhe
journalctl -u hhe -f
```

宿主对接需要把公钥内容填进 `auth.hub.public_key`，详见
[宿主对接指南](https://github.com/ignvex/HomehubExtension/blob/v1.0.0-alpha/docs/hub-integration.md)。

## 从旧版本升级

首个版本，无历史数据需要兼容处理。若从开发中的草案库升级，`serve` 启动时会
自动应用迁移到 schema 5；更稳妥的做法是先单独跑：

```bash
homehub-extension migrate -config /etc/hhe/config.json
```

迁移 0005 会重算存量 `paste.owner_hash`，把按设备计算的归属统一到实例级。
这一步与建表在同一个事务里，失败一起回滚。升级前请先备份：

```bash
homehub-extension backup -config /etc/hhe/config.json -out /var/backups/hhe
```

```bash

make lint          # gofmt / vet / deadcode / 行长 / 函数长度 / import 分组

```

宿主通道的端到端自检见[对接指南第 8 节](https://github.com/ignvex/HomehubExtension/blob/v1.0.0-alpha/docs/hub-integration.md#8-上线自检清单)。

## 已知限制

- OPML 导入导出（M10）未实现。
- 宿主公钥同一时间只支持一把；轮换需要重启，期间旧签名会短暂 401。
- 真实外网站点抓取与真实浏览器 WebCrypto 配对依赖环境，未纳入自动化测试。
- 许可协议尚未选择，默认保留所有权利。
